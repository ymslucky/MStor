# 组件用户体验评估（MStor v8.4）

> 范围：文件选择、列表面板、操作入口、工具栏、侧栏/顶栏、命令面板、弹窗、批量条、空态/加载态。
> 方法：源码量测 + 1440/390 截图 + 现有交互测试。评分 5 分制；本轮已实施「操作入口常显」，并列出下一步。

## 1. 文件选择

| 能力 | 现状 | 评分 | 说明 |
|---|---|---|---|
| 逐个勾选 | ✅ | 4/5 | 行首 checkbox，表头全选支持 indeterminate |
| Shift 范围选择 | ✅ | 4/5 | 桌面 Shift 点选；触屏不可用 |
| Ctrl/Cmd+A 全选 | ✅ | 4/5 | 列表容器聚焦时生效 |
| 长按多选 | ✅ | 3/5 | 触屏长按 500ms；无明确提示 |
| 批量操作 | ✅ | 4/5 | 底部批量条：下载/移动/标签/删除/取消 |
| Esc 清空 | ✅ | 5/5 | 列表、网格、checkbox 焦点均生效 |
| **框选 drag-box** | ❌ | 0/5 | 当前没有框选；空白区域拖动不会选择 |
| 选择态视觉 | ✅ | 4/5 | 列表 ink tint + 3px rail；网格 ink 边框 + ring；黑白高对比 |
| 选中后操作 | ✅ | 4/5 | 已选行/卡可从「更多」再操作；批量条常显 |

结论：批量勾选、范围、全选、批量条已完整；**框选是唯一明显缺口**。建议下一步实现鼠标框选（只从空白区域开始，不干扰行拖拽），并在移动端补一个「选择」模式提示。

## 2. 列表布局

量测：

- 主内容左右内边距：移动 16 / 桌面 32；
- 列表卡片内边距 12，行高 44（紧凑 38）；
- 行内左右 8；表头 8；
- 列宽：选择 28 / 图标 26 / 名称弹性 / 大小 92 / 时间 170 / 操作 auto；
- 分隔线 1px，无斑马纹；
- 网格间距 12，卡片 4:3 缩略图。

评估：

| 项 | 评分 | 说明 |
|---|---|---|
| 信息密度 | 4/5 | 44px 行高适合文件管理；1440 下名称列充足 |
| 横向节奏 | 4/5 | 大小/时间右对齐，名称左对齐；列间只有 cell padding，没有多余 gap |
| 纵向节奏 | 4/5 | 行间仅 1px 线；卡片与工具栏间距 12/16；移动端不拥挤 |
| 对齐 | 4/5 | 表头与行共用 grid 模板；移动端隐藏表头、名称吃满 |
| 空态 | 4/5 | EmptyState 统一，但列表卡片在空列表时高度较小，可再统一下容器高度 |

问题：

- 操作列现在只有一个「更多」，120px 的列宽略宽；可降到 72，把空间还给名称。
- 表头在滚动时不是 sticky（列表内部滚动时表头固定在卡片顶部，当前外层结构已基本满足；若改为整页滚动需要 sticky）。
- 移动端没有列显隐/排序入口，只能依赖默认排序；可作为后续增强。

## 3. 操作入口（本轮已改）

之前：

- 每行 6 个图标仅在 hover/focus 时出现；
- 触屏收进「更多」，桌面用户很难发现重命名/移动；
- 删除等危险动作与常用动作混在一起。

现在：

- 列表每行**常显一个「更多」**（28px，coarse 指针 44px），所有动作进入菜单；
- 网格卡片常显「下载 + 更多」；
- 菜单包含：收藏/取消收藏、打开、下载、分享、重命名、移动、复制到、复制链接、标签、删除、详情；
- 右键菜单与「更多」共用同一份 useNodeActions，行为不分叉；
- 表格/卡片的选中态、hover、焦点仍然独立。

评分：**4.5/5**。发现性明显提升，噪声低于「6 个图标常显」，也比 hover-only 更可靠。
Trade-off：重命名/移动多一次点击；对于高频重命名用户，可后续加一个「双击重命名」或快捷键 F2（已支持键盘 F2）。

## 5. 下一步优先级

1. **框选选择**（P1）：空白区域拖拽矩形选择；Shift 追加；Esc 取消；与行拖拽移动隔离。
2. **操作列宽 120→72**（P2）：把空间还给名称列。
3. **选择模式提示**（P2）：移动端长按进入多选时显示一次轻提示。
4. **列表表头 sticky**（P2）：长列表滚动时保持列头可见。
5. **移动端排序/列显隐**（P3）：当前只有桌面列菜单。
6. **操作菜单键盘可达性**（P3）：菜单已支持 ↑↓/Esc；补「Shift+F10」打开菜单的入口。
