# 公开分享安全与匿名体验

> 产品决策：公开分享允许匿名访问；每个用户一个私有空间，不再提供空间成员/邀请。

## 1. 已有保护

- token 16 字节随机（base64url），不可枚举；
- 可选提取码 PBKDF2-SHA256 100k；
- 有效期、下载次数上限、撤销；
- 下载次数原子扣减；同来源 10 分钟去重，Range/预览不计数；
- 分享创建/撤销写入审计；
- 公开接口在 Access 认证之前注册，匿名可访问 /api/s/*。

## 2. 本轮加固

### 提取码尝试限流

- 维度：token + IP 哈希（不存原始 IP）；
- 10 分钟内最多 5 次错误；
- 达到阈值后锁定 10 分钟，锁定期间即使提取码正确也返回 429；
- 成功解锁后清除失败记录；
- 只对错误尝试写 D1，正常访问不增加写入；
- 失败记录每日 cron 清理。

### 匿名页体验

- 提取码错误、次数过多、过期、撤销、通用加载失败分别有独立文案；
- 通用错误提供「重试」，不直接暴露技术错误；
- 下载失败提示“检查网络后重试”；
- 创建分享时明确提示“任何拿到链接的人都能访问”。

### 不被索引/不泄露来源

- 页面 meta：noindex、no-referrer；
- 公开 API 响应：Referrer-Policy、X-Robots-Tag；
- 分享页不展示内部路径/数据库 id。

## 3. 仍需 Cloudflare 侧配置

应用层限流只能保护提取码尝试，建议在 Cloudflare 控制台增加：

- 对 /s/* 的 WAF Rate Limiting（按 IP，阈值按家庭规模调整）；
- 对异常 UA/爬虫的 Bot Fight Mode 或自定义规则；
- 可选 Turnstile：在连续失败后要求人机验证。

这些规则无法由 Worker 代码替代，也不会自动出现在仓库里。

## 4. 已知边界

- 受密码保护的下载：解锁后签发 1 小时 HttpOnly 分享会话，下载走 a 直链，不再 fetch+blob 全量载入；如果浏览器禁用 cookie，仍需重新输入提取码/复制链接。
- token 分享天然是“持有链接即可访问”；这是产品接受的匿名分享模型。
- 限流键为 token+IP，NAT 后的家庭成员可能共享额度；阈值应保持温和（当前 5 次/10 分钟）。
- 错误尝试记录是 D1 写入；仅在失败时产生，正常访问零额外写入。

## 5. 验收

- 连续 5 次错误提取码后第 6 次（含正确码）返回 429；
- 解锁成功后失败计数清零；
- 过期/撤销/错误页不再是原始异常文案；
- 分享页与公开 API 带 noindex/referrer 头；
- 创建分享时风险提示 100% 触达。
