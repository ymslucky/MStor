# MStor 设计系统 v5 · 工业终端 / 磁带未来主义 / 新野兽派

> 上一版（v4 中性极简）被否，方向改为「磁带未来主义 + 新野兽派」，骨架改为**三栏工作区**。
> 代码真相：`client/src/index.css`（令牌）+ `client/src/components/ui/*`（原语）。

## 1. 三条构成法则

1. **一切都有边框**：2px 墨线（`--color-line-strong`）是默认表达，分隔用 1px 浅线（`--color-line`）。不用阴影做层次，用**硬投影**（offset 实心，非模糊）。
2. **等宽印字**：标签、状态、数值、单位一律 `font-mono` + 大写 + `tracking-wider`（类 `.label-mono`）。正文仍用无衬线保证可读。
3. **近乎无圆角**：`chip/btn/input/card/panel` 全部 0–2px；存量 `rounded-lg/xl/2xl` 由 CSS 统一压到 2px（头像 `rounded-full` 保留圆形）。

## 2. 令牌（亮 / 暗）

| 令牌 | 亮（纸灰） | 暗（石墨） | 用途 |
|---|---|---|---|
| `bg` | `#e9e6dd` | `#14161a` | 页面底（带极淡 4px 网格纹理） |
| `surface-1` | `#f4f1e8` | `#1b1e23` | 面板、列表、卡片 |
| `surface-2` | `#fbf9f3` | `#23262c` | 悬浮层、顶栏、输入框 |
| `ink / ink-2 / ink-3` | `#171613 / #4a463f / #7d786e` | 反转 | 主/次/弱文字 |
| `line / line-strong` | `#b9b3a5 / #171613` | `#3a3e46 / #ede9dd` | 浅分隔 / 墨线 |
| `primary(-text/-soft)` | `#b8730f / #8a5406 / #f2e2c6` | `#f0a94a / #ffc266` | 唯一强调色（琥珀灯） |
| `success / warn / danger` | 深绿 / 赭 / 砖红 | 提亮版 | 仅状态 |

投影：`shadow-card = 3px 3px 0 line-strong`、`shadow-lift = 4px 4px 0`、`shadow-glass = 6px 6px 0`（弹窗）。
圆角：`chip 0 / btn 2 / input 2 / card 2 / panel 2`。动效：90/160ms，线性，无弹跳。

## 3. 原语契约

| 原语 | 工业处理 |
|---|---|
| `Button` | 2px 墨线 + `shadow-card` + 等宽大写；hover 右下位移 1px、active 位移 3px 且投影归零（"按下贴板"） |
| `Input` | 2px 墨线 + `bezal` 内凹 + 等宽字体，focus 变琥珀边框 |
| `Badge` | 方形印标，等宽大写，浅底深字 |
| `GlassCard` | 实色面板 + 2px 墨线 + 硬投影 |
| `IconButton` | 方形 2px 边框，active 态琥珀底 |
| `Skeleton` | 方块 + 浅线边框 |
