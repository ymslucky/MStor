# MStor UI v3 —— 奶白玻璃拟态设计系统实施计划

> 承接前两轮（浅色仪表盘已上线）。本轮按用户设计简报全面重构为 **Arc/Craft/Sonoma 风格的奶白玻璃拟态**。
> REQUIRED SUB-SKILL: subagent-driven-development，按 Batch 1-5 顺序执行，每 Batch 独立 commit + 全绿验收。

## 0. 核心裁定（设计决策说明见文末）

| 决策项 | 裁定 | 为什么 |
|---|---|---|
| 主色 | **#7C9EFF 清透蓝**（文字/描边用加深档 #4C6FE8 保证 4.5:1） | 蓝是云存储「可信轻盈」的本命色；与暖奶橘 CTA 冷暖互补；薄荷绿与 success 语义色过近会混淆 |
| 主题 | light 优先 + dark 兼容，**跟随系统**（prefers-color-scheme），不做手动开关 | 简化范围；CSS 变量双套已备，后续加开关成本极低 |
| 图标 | lucide-react 全站替换 emoji | 简报硬性要求；线性 1.5px 与玻璃风一致 |
| 虚拟滚动 | @tanstack/react-virtual（列表视图启用） | 1000+ 文件不卡；自研窗口化成本高 |
| 明确不做 | 秒传/Worker 算哈希、BucketSwitcher、SyncStatus、分栏视图、二维码 | 均需后端新端点或无对应能力；分栏视图列 v4 |

## 1. 设计令牌（Task B1 落地到 client/src/index.css，完整替换）

```css
@import "tailwindcss";

@theme {
  /* 奶白底体系 */
  --color-bg: #faf9f7;
  --color-bg-sub: #f5f3f0;
  --color-ink: #2d2a26;        /* 暖黑主文字 */
  --color-ink-2: #6b6660;      /* 次 */
  --color-ink-3: #a8a29c;      /* 弱 */
  --color-line: #eeece8;       /* 卡片描边（生硬边框禁用：一律 1px 极浅） */
  --color-primary: #7c9eff;
  --color-primary-text: #4c6fe8;  /* 文字级主色（浅底对比达标） */
  --color-primary-soft: #eef2ff;  /* 主色浅底（选中/hover） */
  --color-cta: #ffb380;           /* 暖奶橘，CTA/高亮 */
  --color-cta-text: #b46a2a;
  --color-success: #7bc9a6;  --color-success-text: #3e7d5f;
  --color-warn: #ffc98f;     --color-warn-text: #9a6414;
  --color-danger: #f5a3a3;   --color-danger-text: #b45454;
  /* 圆角/阴影/动效 */
  --radius-card: 16px; --radius-btn: 10px; --radius-input: 10px;
  --shadow-soft: 0 4px 24px rgb(0 0 0 / 0.05);
  --shadow-glass: 0 8px 32px rgb(0 0 0 / 0.06);
  --ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
  --font-sans: "Inter Variable", ui-sans-serif, system-ui, sans-serif;
  --font-display: "Plus Jakarta Sans Variable", "Inter Variable", sans-serif;
}
/* dark：深灰蓝而非纯黑 */
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #1a1d24; --color-bg-sub: #20242c;
    --color-ink: #f5f3f0; --color-ink-2: #b3aea6; --color-ink-3: #7d786f;
    --color-line: #2b303a;
    --color-primary-soft: rgb(124 158 255 / 0.14);
    --color-cta-text: #ffc79e;
  }
}

/* 玻璃三档（规范：侧栏/弹窗/下拉/Toast/悬浮条/hover 卡片可用；列表主体禁用） */
.glass        { background: rgb(255 255 255 / 0.65); backdrop-filter: blur(16px); -webkit-backdrop-filter: blur(16px);
                border: 1px solid rgb(255 255 255 / 0.8); box-shadow: inset 0 0 0 1px rgb(255 255 255 / 0.6), var(--shadow-glass); }
.glass-strong { background: rgb(255 255 255 / 0.78); backdrop-filter: blur(24px); -webkit-backdrop-filter: blur(24px);
                border: 1px solid rgb(255 255 255 / 0.85); box-shadow: inset 0 0 0 1px rgb(255 255 255 / 0.6), var(--shadow-glass); }
.glass-light  { background: rgb(255 255 255 / 0.45); backdrop-filter: blur(12px); -webkit-backdrop-filter: blur(12px);
                border: 1px solid rgb(255 255 255 / 0.7); }
/* dark 下玻璃面色重写为 rgba(255,255,255,0.08)（media query 同上结构） */
/* prefers-reduced-transparency → 三档全部实底（bg-sub/白）且去 blur */
/* backdrop-filter 元素统一 will-change: backdrop-filter（性能简报要求） */

/* 柔光光晕（页面 1-2 处径向渐变，奶白通透感） */
.glow-radial { position: fixed; inset: 0; pointer-events: none; z-index: 0;
  background:
    radial-gradient(720px 420px at 12% -8%, rgb(124 158 255 / 0.10), transparent 62%),
    radial-gradient(640px 380px at 100% 12%, rgb(255 179 128 / 0.09), transparent 60%); }

/* 动效关键帧（入场 stagger / 弹窗弹性 / 骨架 shimmer / 淡出折叠） */
@keyframes item-in { from { opacity: 0; transform: translateY(8px) scale(0.98); } }
@keyframes modal-in { from { opacity: 0; transform: scale(0.94); } }
@keyframes shimmer { from { background-position: 200% 0; } to { background-position: -200% 0; } }
/* 列表项入场：animation: item-in 250ms var(--ease-spring) both; 每项 animation-delay: i*20ms（≤10 项封顶） */
```

字体：`npm i @fontsource-variable/inter @fontsource-variable/plus-jakarta-sans`，main.tsx 引入；正文 14/15px，标题 font-display，数字 `tabular-nums`。列表行高 48px。

依赖新增：`lucide-react`、`@tanstack/react-virtual`、上述字体包。

## 2. 布局系统（Task B2）

- **桌面**：左可折叠侧栏（展开 240px / 折叠 64px，折叠钮在侧栏顶，状态存 localStorage）+ 顶部工具栏 56px（面包屑 | SearchBar | 视图切换 | 上传按钮）；主内容区自适应全宽（保留上轮「铺满」要求），glass 侧栏 sticky。
- **移动**：底部 Tab（浅玻璃）+ 全屏内容，安全区保留。
- **可拖拽侧栏宽度**：折叠态与展开态两档切换即可（自由拖宽 YAGNI，简报的"可折叠"已满足主诉求——备案）。
- 背景：`.glow-radial` 挂最外层；主内容卡片白底 `shadow-soft`。
- 断点沿用 Tailwind 默认 sm640/md768/lg1024/xl1280/2xl1536。

## 3. 组件与交互（Task B3/B4）

- **FileBrowser**：列表/网格双视图（虚拟滚动用于列表 ≥50 行）；多选 checkbox + Shift 范围选 + Ctrl/Cmd 点选 + Ctrl+A 全选（抽 `hooks/useFileSelection.ts` 可单测）；键盘 ↑↓ 移动焦点、Enter 打开、Delete 删除、F2 重命名、空格预览（`hooks/useKeyboardNav.ts`）；拖拽：文件拖入=上传（已有），**拖文件到文件夹行=移动、拖到面包屑=移动到该目录**（HTML5 DnD，dragover 高亮 2px 主色）。
- **FileRow/FileCard**：Lucide 类型图标（图片文件用缩略图）、大小/时间 tabular-nums、共享标记（Badge）。
- **UploadPanel**：玻璃悬浮条；分片进度、失败重试（已有）、「暂停」= abort（续传需后端，备案）。
- **SearchBar**：防抖 300ms（已有）+ 前端过滤当前目录的类型/时间 chips（纯前端 filter）。
- **PreviewModal**：glass-strong 弹窗 + modal-in 弹性动画；图片/视频/PDF/文本（能力已有）。
- **ShareDialog**：外链/密码/有效期（已有）+ 复制（已有）。
- **StorageMeter**：侧栏内环形 SVG 用量 + 「≈ ¥0/月（R2 免出口流量）」费用注记。
- **ContextMenu**：玻璃浮层 glass-light blur(12px)；项：打开/下载/分享/重命名/移动/复制链接/删除/详情（详情=只读属性弹窗）。
- **AdminPanel/AuthPanel**：既有逻辑，皮秒级重绘为奶白风；AuthGuard=RequireAuth（登录落地页已符合）。
- **Toast**：玻璃 glass + 图标；**EmptyState**：Lucide 大图标 + CTA。
- 上传暂停/续传、秒传：不做（见裁定表）。

## 4. 动效与无障碍

- 全站动效 200-350ms + `--ease-spring`；`prefers-reduced-motion` 全局归零（已就绪，保留）。
- 焦点环：2px 主色 + offset 2px（已有，色值换 primary-text）。
- 文件区 `role="grid"` + aria-rowcount；上传进度容器 `aria-live="polite"`；图标按钮 aria-label 既有约定不变。
- 对比度：玻璃上正文放白卡或加 `bg-ink/5` 底衬；primary 文字一律用 primary-text。
