# MStor 功能升级报告

> 日期：2026-09-28 ｜ 版本基线：`4c25ede`（生产 Version 30f28995）

## 一、现状功能地图

### 服务端（Cloudflare Workers + D1 + R2，9 个路由模块）

| 模块 | 功能点 |
|---|---|
| auth | OIDC 登录（首登自动建户/建根目录）、rp-initiated logout（id_token_hint）、session JWT |
| files | 文件/目录列表（含面包屑）、重命名、移动（含跨目录唯一名冲突处理）、小文件直传（≤60MB）、内容下载（`?dl=1`） |
| dirs | 目录创建、`POST /api/dirs/ensure`（幂等建目录，嵌套上传依赖） |
| uploads | 大文件 multipart：init / part-urls（R2 预签名）/ complete / abort |
| shares | 分享创建（默认 7 天，可密码、可永久）、列表、撤销、批量撤销；公开访问校验（密码/过期/撤销） |
| trash | 回收站列表（≤500）、单项恢复/彻底删除、批量恢复/批量清理、每日定时清理（保留天数读 settings 表，env 回退） |
| search | 文件名搜索 |
| me | 用户信息（`self` 登录账号与当前空间分离）、WebDAV 密码；admin：用户列表/停用/配额/改名/角色、act-as 切换空间、动态配置（回收站保留天数） |
| dav | WebDAV 网关（Windows 映射驱动器 / iOS 文件 App） |

### 客户端（Vite + React 19 + Tailwind v4 + TanStack Query）

- **AppShell**：奶白玻璃拟态、侧栏（桌面）/底部 Tab（移动）、act-as 横幅、登录落地页（用户主动发起 OIDC，防限流）、session 过期防抖重认证
- **Browser**：列表/网格双视图、面包屑（可拖拽移动）、多选（Ctrl/Shift/全选）、键盘导航（↑↓/Enter/Delete/F2/Space）、右键菜单、拖拽上传（`webkitGetAsEntry` 嵌套文件夹）、拖拽移动、类型/时间过滤、批量删除（含彻底删除）/移动/下载、上传队列悬浮条（真实进度 + EMA 网速）
- **Shares/Trash/Share 页**：分享批量撤销；回收站批量管理 + 清空；公开分享页（访问码门 + 子树浏览 + 下载）
- **SettingsPage**：三 Tab（账户 WebDAV / 上传并发 1–16 / 管理：用户管理 + 回收站保留天数动态配置）
- **PWA**：manifest + SW 静态资源 CacheFirst + 离线提示条

### 质量基线

server 121 / client 144 测试全绿，tsc 双管线 0 错误，build gzip ≈120KB。

## 三、待升级建议（按优先级）

### P0 — 核心能力补强

1. **断点续传**：大文件分片上传记录 uploadId（localStorage/IndexedDB），刷新/网络中断后跳过已完成分片继续。目前「暂停」即丢弃。
2. **秒传（hash 去重）**：Web Worker 计算 SHA-256，`/api/uploads` 先查重，命中直接引用已有 R2 对象，大文件重复上传零流量。
3. **分享后管理增强**：分享项的下载统计趋势、过期分享归档列表、二维码（当前仅文本链接）。

### P1 — 体验与效率

4. **图片/视频增强**：缩略图服务端生成（R2 + Image Resizing 或 Worker Canvas），列表网格视图直接出图，替代类型图标。
5. **在线预览扩展**：Office 系（docx/xlsx）预览、Markdown 渲染、代码高亮编辑后保存。
6. **搜索增强**：全文检索（D1 FTS5）、按类型/大小/时间/所有者的服务端过滤（当前类型/时间为前端过滤当前目录）。
7. **文件版本/回收站时间线**：同名覆盖保留历史版本。

### P2 — 协作与生态

8. **多人协作**：目录级共享给站内成员（当前仅公开外链）、协同标注。
9. **API Token**：个人 API 密钥管理，开放 RESTful API 给第三方。
10. **Webhook/通知**：分享被下载、配额临期、回收站即将清理等站内通知中心。
11. **审计日志**：admin 可查登录/删除/分享等敏感操作记录。

### P3 — 运维

12. **admin 仪表盘**：存储总览、用户活跃、R2 Class A/B 操作量估算（费用透视）。
13. **数据导出**：账户全量打包下载（(zip 流式)），降低锁定感。

## 四、风险评估

- **分片并发 16** 与 Workers 免费档 CPU 限制无冲突（直传 R2 预签名 URL 不占 Worker CPU），但浏览器高并发占满上行带宽，移动端建议 ≤4（可在设置页自行调低）。
- **settings 表**为键值白名单设计，后续加配置项需同步 server 校验 + 前端表单，注意保持两端同步。
