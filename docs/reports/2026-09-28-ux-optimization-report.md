# MStor 用户体验优化报告

> 日期：2026-09-28 ｜ 覆盖范围：web 端（桌面 + 移动 PWA）

## 一、本轮已完成的体验优化（附动机）

### 信息架构
| 优化 | 为什么 |
|---|---|
| 主内容块去冗余：KPI 4 卡→1 张存储卡，快捷操作行移除 | 管理分享/回收站与侧栏、底部 Tab 重复；上传/新建合并进文件工具栏——首屏直达文件列表，省约 120px 垂直空间 |
| 上传/新建文件夹/上传文件夹收进工具栏 | 动作贴近操作对象（列表），空目录时保留大 CTA 引导 |
| 设置页 Tab 化（账户/上传/管理） | 设置项增多后平铺过长；按「频率 × 权限」分组，管理项仅 admin 可见 |

### 上传体验
| 优化 | 为什么 |
|---|---|
| 小文件改 XHR 直传 | fetch 无上传进度事件，之前小文件进度恒为 0 |
| 大文件分片 XHR + 字节级聚合 | 之前分片用 fetch，传完一个分片才跳一次进度，Safari 传 1.3G 前几分钟「无进度无网速」 |
| EMA 速度采样 + 100ms 节流 | 平滑网速显示，避免进度回调抖动导致 UI 高频重渲 |
| 上传并发数 1–16 可配置（默认 3） | 之前队列串行 + 分片 3 并发，总并发封顶 3；大文件吞吐受限 |
| 删除弹窗加「彻底删除」 | 高频路径免跳回收站二次操作 |
| 分享默认 7 天 | 永久外链是安全负债；7 天是常见分享周期，仍可手动改永久 |
| 回收站批量 + 清空 | 逐项操作在几十个文件时不可接受 |
| 分享批量撤销 | 同上 |
| 用户改名/角色分配 | 之前 admin 只能改配额和停用，名册管理能力缺失 |

### 认证与安全体验
| 优化 | 为什么 |
|---|---|
| 登录落地页（用户点击发起 OIDC） | 自动重定向每次消耗 IAM 限流配额，曾触发 429 |
| session 过期防抖重认证 | 模块级守卫，避免多请求同时触发重定向风暴 |
| 登出清理 act-as 标记与 cookie | 残留 `mstor_act_as` 曾导致下次登录仍处于他人空间视图 |
| `/api/me` 返回 `self`（登录账号） | admin act-as 查看他人空间时，侧栏错误显示对方名字/角色 |
| admin API 跳过 act-as 头 | 残留 act-as 状态时用户管理会 403 |
| 不可逆操作全部应用内确认弹窗 | 替代原生 confirm/页面跳转，可写清后果（彻底删除、清空回收站、撤销分享、退出登录） |

## 二、现存体验问题（建议下一轮处理）

1. **缩略图缺失**：网格视图用类型图标占位，图片类文件浏览体验明显弱于主流网盘（依赖 P0 缩略图服务）。
2. **大文件上传不可恢复**：刷新页面即丢 uploadId，已传分片作废——重传 1G+ 文件是最大痛点。
3. **移动端上传面板**：底部悬浮条在 iOS Safari 底部工具栏区域可能遮挡，需真机验证 safe-area 场景。
4. **无障碍欠账**：文件列表已有 role=grid，但 Shift 多选/拖拽移动无键盘替代路径；焦点环在玻璃面上对比度需复验。
5. **暗色模式**：设计规范已定义（#1A1D24 底）但未实现切换入口。
6. **操作反馈粒度**：批量删除/移动无进度（只有完成 toast），100+ 项时体感「卡死」。
7. **搜索**：仅当前会话文件名匹配，无结果页、无历史、无全文。
8. **错误文案**：部分服务端错误直出（如 R2 5xx），未映射为用户可行动的文案。

| 维度 | 当前 | 一轮前 | 主要差距 |
|---|---|---|---|

| 信息密度/首屏效率 | 4 | 3 | 缩略图 |
| 批量操作 | 4 | 2 | 批量进度反馈 |

## 四、验证方式建议

- 上传体验：Safari/Chrome 各传 1G+ 文件，观察进度斜率与网速稳定性；并发 8/16 与 3 对比耗时。
- 回归基线：每次改动后跑 `npx vitest run`（server 121）+ `npm run test:client`（144）+ `npm run check`。
- 真机清单：Windows 映射驱动器、iOS 文件 App（WebDAV）、添加到主屏幕后的离线冷启动。
