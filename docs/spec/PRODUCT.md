# 产品规范

状态：Accepted
适用版本：当前 `master`
维护规则：产品行为、功能边界或默认策略变化时必须更新本文。

## 1. 产品定位

MStor 是私有家庭云盘，面向单一家庭或小型可信群体：

- 数据归属清晰：每个用户一个私有 workspace。
- 安全优先：Cloudflare Access 控制入口，服务端强制租户隔离。
- 可恢复优先：删除进入回收站，彻底删除需显式操作。
- 低运维优先：优先使用 Cloudflare 托管能力，不自建服务器。

## 2. 用户与角色

| 角色 | 来源 | 能力 |
|---|---|---|
| Pending user | Access 放行但 `approved_at IS NULL` | 仅能读取 `/api/me` 查看待审状态 |
| Member | 管理员批准 | 管理自己个人空间内的文件、分享、标签、收藏 |
| Platform admin | `users.platform_admin = 1` | 管理用户、注册、默认配额、平台设置、审计概览，可 act-as 排障 |

平台管理员角色与 workspace 角色正交。act-as 是排障上下文，不是普通用户能力。

## 3. 核心用户旅程

### 3.1 注册与审核

1. Cloudflare Access 放行可信身份。
2. 若允许注册，Worker 自动创建用户与个人空间。
3. 若要求审核，新用户处于 pending，管理员批准后可用。
4. 首个登录用户可成为平台管理员；后续准入由 Access 白名单和审核开关控制。

### 3.2 文件管理

- 浏览目录、面包屑、列表/网格、排序、筛选。
- 新建目录、上传、下载、重命名、移动、复制、删除。
- 支持批量操作、键盘导航、框选、移动端适配。
- 文件与目录共享同一棵 node tree；目录不可当作文件下载。

### 3.3 上传

- 小文件直传。
- 大文件 multipart 断点续传。
- 同 workspace 内 SHA-256 命中可秒传。
- 上传队列可跨刷新恢复，失败可重试。
- 客户端可为图片/视频生成缩略图并上传到独立 R2 key。

### 3.4 回收站

- 删除是软删，目录会整棵进入回收站。
- 支持单个/批量恢复与彻底删除。
- 恢复时父目录不存在则恢复到根。
- 保留天数由全局设置控制；过磅清理由 cron 执行。

### 3.5 分享

- 可对文件或目录创建公开链接。
- 可设置有效期、提取码、最大下载次数。
- 密码验证后签发匿名短会话，支持浏览器原生直链下载。
- 分享目录可浏览子目录并下载其中文件。
- 撤销、过期、达到次数后不可访问。

### 3.6 检索与整理

- 文件名/目录名搜索，支持类型、大小等过滤。
- 标签空间内共享，可绑定/解绑节点。
- 收藏和最近访问按用户隔离。

### 3.7 管理与审计

- 管理员可查看用户、空间、存储、审计概览。
- 可批准、停用、调整用户配额。
- 可配置注册开关、审核开关、默认配额、回收站保留天数、审计开关。
- 高风险动作写 `audit_events`；审计目标是动作级，不是全量访问日志。

## 4. 明确非目标

- 不提供匿名注册和公开上传。
- 不提供团队共享 workspace、成员邀请、角色管理 UI。
- 不做 WebDAV、FTP、NAS 协议兼容。
- 不做正文 OCR / 全文检索。
- 不承诺离线编辑；PWA 仅保留导航与体验能力。
- 不自建邮件系统；当前通知仅站内。
- 不做通用多租户 SaaS 计费。

若未来改变以上边界，必须先新增或修订 ADR。

## 5. 产品不变量

1. 普通用户永远不能看见或推断其他用户空间资源的存在。
2. 不可见资源返回 404；无权限的显式操作返回 403，但不能泄露他人资源详情。
3. 删除默认可恢复；彻底删除必须显式触发。
4. 分享链接是唯一受控匿名入口，且必须受有效期/提取码/次数/撤销约束。
5. 上传不能绕过 workspace 配额与站点全局预算。
6. 管理员 act-as 只用于排障，进入动作必须审计一次。
7. UI 不能为了效率牺牲键盘、读屏、对比度和移动端可用性。

## 6. 验收口径

每个功能至少覆盖：

- 正常路径；
- 空状态 / 错误状态 / 加载状态；
- 跨租户访问被拒绝；
- 并发或重复请求不产生脏数据；
- 配额、存储统计、审计与实际状态一致；
- 桌面与移动核心交互；
- 对应 API 契约测试。

## 7. 已知保留能力

`file_versions` 表当前是 schema 预留，未提供用户可见版本管理功能。不得在 UI 或营销说明中宣称版本历史；若启用，必须先补产品规范、迁移策略、配额规则与恢复测试。
